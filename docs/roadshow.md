## 三、核心功能矩阵

### 🎭 6 大面试场景
| 场景 | 考官 | 特色 |
|------|------|------|
| 💼 求职面试 | 张经理（10年大厂面试官） | 项目深挖 + 技术追问 |
| 📚 教资面试 | 王老师（20年教龄教研员） | 试讲 + 结构化问答 |
| 🗣️ 雅思口语 | Mr. Smith（剑桥认证考官） | 语音交互 + 三部分全流程 |
| 🏛️ 公务员面试 | 李主任（8年公考评审） | 结构化面试 + 时政热点 |
| 🎓 考研复试 | 陈教授（博导） | 学术潜力 + 专业基础 |
| 💎 MBA 面试 | 刘总监（企业高管） | 领导力 + 职业规划 |

### 🧠 AI 核心能力
- **多轮追问**：根据上一轮回答自然深入，不是预制问题列表
- **5 种面试风格**：标准 / 严格 / 引导 / 压力 / 温和，可随时切换
- **6 阶段面试流程**：自我介绍 → 项目深挖 → 基础考察 → 进阶能力 → 系统设计 → 行为面试
- **技术深挖模式**：检测到 Redis / Kafka / RAG 等关键词，自动进入专题追问
- **防幻觉机制**（最高优先级规则）：绝对禁止编造用户简历内容，只能用用户实际说过的信息
- **程序化选题**：加权召回真实面经 > 开源题库 > AI 生成，S/A/B/C 四级分层

### 📊 面试后体系
- **多维度评分报告**：雷达图 + 各维度分数 + 优势 / 改进建议
- **AI 参考答案对比**：STAR 法则生成参考答案，与自己的回答对比学习
- **委员会评审**（今日上线）：3 位不同立场 AI 评审员并行打分 + 主席合成 + 一致性分析
- **面试记录回溯**：查看过往每一次完整对话 + 评分报告
- **成长档案**：练习次数 / 得分趋势 / 场景排行榜

### 🏅 游戏化激励
- **12 种成就徽章**（新手入门 / 坚持打卡 / 场景挑战 / 特殊成就）
- 自动解锁判定，面试结束即时弹出

### 🎙️ 语音交互
- 阿里云 NLS 语音识别 + TTS
- 雅思口语场景支持完整语音对话
- SDK 不可用时自动降级

### 👤 数字人考官
- 2D 立绘 + 5 种表情（中性 / 微笑 / 思考 / 鼓励 / 结束）
- 6 套场景匹配形象（男女各一套）

## 四、技术架构

```
前端层      Jinja2 模板 + 原生 CSS/JS + Chart.js（雷达图）
  │
Web 层      Flask 3.x + Flask-SocketIO（实时 WebSocket 对话）
  │
业务层      Skill 系统（6场景引擎）+ Tool Calling（18 工具）
  │         + Workflow 流水线（5 阶段）+ Agent 编排器（多 Agent 并行）
  │
AI 层       DeepSeek Chat API（主）+ 预设题库降级（328+ 题）
  │
数据层      SQLite（本地）/ Supabase PostgreSQL（生产）
```

### 韧性保障
- ⏱️ 20s 超时 + 2 次重试（指数退避）
- 📚 三级降级：实时 API → 题库兜底 → 硬编码问题
- ✅ 5 项韧性测试全部通过
- 🔄 API 故障后自动回退，用户无感知

## 六、竞争力护城河

1. **不是通用 Chatbot** — 6 套独立考官人设 + 评分维度 + 追问策略，YAML 驱动，可无限扩展
2. **防幻觉是最高优先级** — 几乎所有 LLM 应用避而不谈的问题，我们正面解决并写入了 system prompt 最强约束
3. **真数据闭环** — 牛客网 / 知乎 / CSDN 真实面经采集 → 分级评分 → 加权召回 → 面试使用 → 反馈优化
4. **多 Agent 评审** — 业界少见的 AI 面试场景多 Agent 实践，3 位评审员并行打分 + 一致性分析
5. **工程韧性** — 超时重试 + 三级降级 + 幂等保护，不是 Demo 是 Product
6. **完整可部署** — Render 一键上线，有登录 / 有数据库 / 有历史记录 / 有成长档案

## 七、演示路径（推荐 5 分钟流程）

```
1. 注册/登录 → 看到首页（3 秒）
2. 场景中心 → 选择「求职面试」→ 填写目标岗位和背景
3. 选择面试风格（如「压力型」）→ 开始面试
4. 与 AI 考官对话 3-4 轮（展示追问深度）
5. 点击结束 → 查看评分报告（雷达图 + 多维度 + 参考答案对比）
6. 点击「面试记录」→ 查看过往所有面试历史
7. （可选）展示委员会评审结果：agreement_score + 3 位评审员独立分数
```
